# drift_tutorial

Driftは、Flutterアプリケーションのための強力なSQLiteデータベースソリューションです。

## 主な特徴

### 💪 強力なORMの機能
- SQLiteテーブルをDartクラスとして表現
- タイプセーフなデータベース操作
- エンティティクラスの自動生成
- Nullセーフティなコード生成

### 🔧 柔軟なクエリビルダー
- 型安全なSQLクエリの構築
- 複雑なJOINやサブクエリのサポート
- カスタムSQL文の実行
- コンパイル時のクエリ検証

### 🚀 開発生産性の向上
- コード生成による型安全性の確保
- IDEサポートによる補完機能
- デバッグしやすいクエリ構文
- テストの容易さ

### 📱 Flutterに最適化
- リアクティブなストリームベースのデータ更新
- トランザクションのサポート
- マイグレーション機能
- 非同期操作のサポート
- カスタムタイプコンバーター

## セットアップ

必要なパッケージをインストール：

```shell
flutter pub add drift \
  sqlite3_flutter_libs \
  path_provider \
  path \
  build_runner \
  drift_dev
```
